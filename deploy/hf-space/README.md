# Assistente médico virtual (Tech Challenge Fase 3, FIAP)

Demonstração do assistente clínico do Hospital Santa Aurora, um hospital **fictício**: Qwen2.5-1.5B ajustado com QLoRA em dados sintéticos e anonimizados, busca semântica nos protocolos internos, fluxos LangGraph com aprovação humana obrigatória e trilha de auditoria.

Todos os dados são fictícios e o projeto é acadêmico: **não usar na prática clínica**. O acesso é protegido por login.

Código-fonte, relatório e instruções: https://github.com/fiap-pos-org/fiap-tc-fase3
